## 2. Detailed description

### 2.1 The `Emulator` trait (§7.1)
Methods: `feed(&mut self, &[u8])`, `resize(cols, rows)`, `modes() -> TermModes`,
`render(area, buf, view)` (implemented in M1-10, declared here), `take_responses() -> Vec<Bytes>`,
`scrollback_len()`, `search(re, dir, from) -> Option<Match>`, `snapshot_vt() -> Bytes`. Add the
non-spec helpers needed by other tasks:
- `take_events() -> Vec<TermEvent>` (title, bell, clipboard store request, cwd via OSC 7, OSC 133 marks for
  M7-01, hyperlink hover data),
- `cursor() -> CursorInfo` (position, shape, visible),
- `grid_text(range) -> String` (for copy mode and history capture),
- `set_color_scheme(&ColorScheme)` (for answering OSC 10/11/4 queries),
- `set_pixel_size(cell_w, cell_h)` (for `TextAreaSizeRequest`).
The trait is object-safe (`Box<dyn Emulator>`) and `Send`.

`TermModes`: DECCKM (app cursor), DECKPAM (app keypad), mouse mode (none/1000/1002/1003) and encoding
(default/1006 SGR/1005/1015), bracketed paste (2004), focus reporting (1004), alternate screen,
modifyOtherKeys level, kitty keyboard flags requested by the remote, cursor shape and visibility.

### 2.2 `AlacrittyEmulator`
- Holds an `alacritty_terminal::Term<Listener>` and a `vte::ansi::Processor`. `feed` calls
  `processor.advance(&mut term, bytes)`.
- `Listener: EventListener` pushes into an internal `Vec<AlacEvent>` (no channels, keeping it synchronous), drained after
  each `feed` into:
  - `PtyWrite(String)` → **responses** (DA1/DA2, DSR CPR, DECRQM, XTVERSION, OSC 10/11 replies) → returned by
    `take_responses()`. **Critical** (§7.1): without this, vim and fish hang.
  - `Title(t)` / `ResetTitle` → `TermEvent::Title`, truncated to 256 chars (§17), with control chars stripped.
  - `Bell` → `TermEvent::Bell`.
  - `ClipboardStore(ty, text)` → `TermEvent::ClipboardWriteRequest`. The **policy** (`never`/`ask`/`always`,
    §7.3) is applied by the UI (M1-11), and the emulator only reports.
  - `ClipboardLoad(..)` → **always deny**: reply nothing (or an empty response, as xterm does for denied reads). Never call
    the formatter with clipboard contents. This is a tested security invariant (§17).
  - `ColorRequest(index, fmt)` → answered from the pane's `ColorScheme` (§7.1).
  - `TextAreaSizeRequest(fmt)` → answered with the pane size in cells and pixels.
  - Any OSC that would execute or open something (none in alacritty by default) → ignored.
- **Query responses are generated by the emulator, never echoed from remote input** (§17).
- Scrollback configured from `terminal.scrollback` (default 10,000, §7.1), set at construction.
- `snapshot_vt()` (§14.2) produces a VT byte stream that recreates the visible screen: `ESC[?1049h` if
  the alt screen is active, clear screen, home, then each row with SGR transitions for fg/bg/flags (bold, dim, italic,
  underline styles, inverse, hidden, strike), wide chars, cursor position and shape (`DECSCUSR`), and mode set
  sequences (DECCKM, bracketed paste, mouse modes, focus). No scrollback.

### 2.3 Charsets (§7.1)
- `CharsetCodec` wraps `encoding_rs`: `decoder.decode_to_string(chunk, &mut out, last=false)` handles
  multibyte sequences split across reads. On the input path, `encoder` converts UTF-8 input to the host charset.
- Applied **outside** the emulator: in the session read loop before `feed`, and in the write path after key
  encoding. The emulator always consumes UTF-8.
- For a host `charset` label that `encoding_rs::Encoding::for_label` doesn't recognize, validation fails on save
  (M1-07 form) and the session falls back to UTF-8 at runtime with a warning.

### 2.4 Fallback emulator (§7.1, §22.4)
Keep the trait narrow enough that a `vt100`-crate implementation is feasible. **Do not implement it now.** Write a
`docs/emulator.md` note listing what the trait relies on, so the swap cost is known.

### 2.5 Recorded-stream tests (§19)
`crates/sverb-term/tests/streams/*.bin` contains byte streams captured from real programs (vim opening a
file and quitting, htop for 1 s, tmux split, less on a man page, a `printf` color test, a UTF-8/emoji/CJK test, a
DECSTBM scroll-region test). Each has an expected final-grid snapshot (`insta` text snapshot of visible rows plus
cursor). Record them with `script -q -c` (Linux) under a fixed `TERM` and size (80×24), and document how to
re-record.

## 4. Test cases to implement

**T-01 (integration, fixtures)** Replay each recorded stream at 80×24, and the final grid matches the snapshot.

**T-02 (unit) DA1.** `feed(b"\x1b[c")` → `take_responses()` contains a primary DA reply (e.g. `\x1b[?6c`
per alacritty).

**T-03 (unit) DSR CPR.** Move the cursor to (5,10), then `feed(b"\x1b[6n")` → the reply is `\x1b[10;5R` (row;col, 1-based).

**T-04 (unit) OSC 11 color query** → the reply contains the scheme background in `rgb:rrrr/gggg/bbbb` form.

**T-05 (unit) Responses are not echoes.** Feeding `\x1b[6n` as part of printable text inside an OSC string doesn't
produce a CPR.

**T-06 (unit) OSC 52 read denied.** `feed(b"\x1b]52;c;?\x07")` → no response contains clipboard data, and no
`ClipboardLoad` reaches the UI.

**T-07 (unit) OSC 52 write reported.** `\x1b]52;c;aGVsbG8=\x07` → `ClipboardWriteRequest("hello")`.

**T-08 (unit) Title cap.** A 10k-char OSC 2 → title ≤ 256 chars, with no control chars.

**T-09 (unit) Modes.** `\x1b[?1h` → DECCKM on. `\x1b[?2004h` → bracketed paste on. `\x1b[?1000h\x1b[?1006h` →
mouse 1000 with SGR. `\x1b[?1049h` → alt screen.

**T-10 (unit) Split UTF-8.** Feed `é` (0xC3 0xA9) in two calls → one cell `é`.

**T-11 (unit) Charset decode.** Host charset `windows-1252`: bytes `0x80` → `€` in the grid. The input `€` is encoded
to `0x80`.

**T-12 (unit) Shift_JIS split across reads** decodes correctly.

**T-13 (unit) Wide chars.** `中` occupies 2 cells with a spacer, and the cursor advances by 2.

**T-14 (unit) Resize** shrinks and grows without panicking and reflows per alacritty semantics. The scrollback length is preserved.

**T-15 (unit) snapshot_vt round-trip.** Feed a colorful screen into emulator A, take `snapshot_vt()`, feed it into
a fresh emulator B of the same size, and the visible grids (chars + attributes + cursor + modes) are identical. Repeat for
the alt screen.

**T-16 (unit) Scrollback size** honors the config (100 lines → `scrollback_len() ≤ 100` after 1,000 lines).

**T-17 (unit) Search.** Regex `error\d+` found backwards from the cursor across scrollback.

**T-18 (fuzz stub)** `fuzz_targets/emulator_feed.rs`: arbitrary bytes never panic.

**T-19 (bench)** Parse throughput on a 100 MB mixed stream (text + SGR) is ≥ 100 MB/s (§19). Record it, and fail the
bench gate in M7-06.
